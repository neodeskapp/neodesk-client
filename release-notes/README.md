One file per desktop release, `<tag>.md` (`desktop-v1.5.0-rc.4.md`), committed before the tag: the release workflow puts it first in the notes, then a Downloads heading with the download table and the change list, and keeps today's generated notes when there is no file. For a release that is out already, run `scripts/generate_release_download_table.py` with `--intro-md-file release-notes/<tag>.md` over the release's file names and `gh release edit <tag> -R neodeskapp/neodesk-client --notes-file` the result.

The first image is the release card, from git: in neodeskapp/website run `node release-card.ts <this checkout> <tag> "<title>" --product "Desktop client" --accent lime` (add `--previous <tag>` when the tag before was never published), commit and push `public/img/releases/<tag>/`, and link it as `https://raw.githubusercontent.com/neodeskapp/website/<commit>/public/img/releases/<tag>/card.png` with `width="800"` and alt text.
